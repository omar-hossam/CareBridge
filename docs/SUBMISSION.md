## 🎯 What Is CareBridge?

A **privacy-first donation platform** connecting patients in need, verified hospitals, and donors worldwide.

**No patient photos. No real names. Just bills and trust.**

---

## ❓ Problem

Millions can't afford healthcare. Existing platforms:

- Exploit patient privacy (forced photos + sad stories)
- Take days to verify
- No proof where money goes

**CareBridge fixes all three.**

---

## ✅ Our Solution

| Scenario | Who | Flow |
| :--- | :--- | :--- |
| **A** | Hospital | Treats free → posts request with cost → donor pays hospital |
| **B** | Individual | Posts medicine need → adds total cost → swears data is correct → donor pays |


> **Donors decide. Platform connects. Privacy always.**

---

## 🔐 Privacy First

| Included | NEVER Included |
| :--- | :--- |
| Medicine names | Patient photo |
| Costs | Patient real name |
| Hospital stamp | National ID |
| Fake patient ID | Phone number |

**Legal swear checkbox + police warning for fake requests.**

## 🚀 Features Built (MVP)

- ✅ Hospital registration with government document upload
- ✅ Role-based access control (donor / individual / hospital / admin)
- ✅ Hospital approval pipeline with document verification
- ✅ Admin verification dashboard
- ✅ Individual request form (medicine, costs, legal checkbox)
- ✅ Hospital request form
- ✅ Browse requests page
- ✅ Donor donation flow
- ✅ Supports automatic light/dark mode based on your system theme.
- ✅ Responsive web design for all screens
